# DoA Tracker

A Reachy Mini app that turns toward whoever is speaking, using the mic array's
direction of arrival (DoA).

## Settings

Open the settings page at `http://<robot>:8042` to choose what turns toward the sound:

| Mode | Behavior                                                    |
|------|-------------------------------------------------------------|
| Head | The head looks toward the sound (default).                  |
| Body | The body turns toward the sound and the head faces forward. |
